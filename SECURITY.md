# Security

launchcodes pushes to production, so a way around one of its checks matters to everyone who uses it: a push
without the owner's yes, something pushed that wasn't built and approved, a secret that gets through, or the
production query running something other than a read.

Please report one privately: on GitHub, open this repository's **Security** tab and choose **Report a
vulnerability**. Don't open a public issue for it.

Only the latest version is supported.
